# CPAL OpenReview

CPAL 2027 uses **OpenReview** to host submissions, reviews, author responses, and discussion. Proceedings submissions are reviewed double-blind; Recent Spotlight submissions are reviewed single-blind.

See the [Submission Tracks]({{ site.baseurl }}/call_for_papers/#submission-tracks) page for submission and review policies and the [Key Dates]({{ site.baseurl }}/deadlines/) page for the review calendar.

## Proceedings LaTeX template

[Download CPAL 2027 LaTeX template (ZIP)]({{ '/assets/CPAL-2027-template.zip' | relative_url }}){: .btn .btn-primary }

Import the ZIP into Overleaf as a new project, or compile it locally. The ZIP contains the LaTeX source, style file, and example bibliography.

For **Proceedings Track** submissions, keep the default anonymous submission mode, which hides author names and adds line numbers. Do not enable the `final` or `preprint` options for review. The main text is limited to **nine pages**, including figures and tables; references and appendices do not count toward the limit.

For **Recent Spotlight Track** submissions, follow the [separate submission requirements]({{ '/call_for_papers/' | relative_url }}#recent-spotlight-track-non-archival); reviewing is single-blind and submissions should not be anonymized.
